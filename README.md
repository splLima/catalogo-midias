 Catálogo de Mídias

Aplicação web desenvolvida para o gerenciamento de um catálogo de filmes, livros e músicas.

 Funcionalidades
- Cadastro, edição e exclusão de itens (CRUD).
- Sistema de busca com filtragem dinâmica por título, autor ou gênero.
- Persistência de dados em arquivo texto (`.txt`) salvo diretamente na pasta do projeto.
- Validação de formulários e tratamento de erros de conversão.

  Tecnologias Utilizadas
- **Linguagem:** Java (Java EE 7)
- **Framework:** JavaServer Faces (JSF 2.2)
- **Servidor de Aplicação:** GlassFish 4.1.1
- **IDE:** NetBeans 8.0.1
- **Controle de Versão:** Git e GitHub

  Como Executar o Projeto
1. Clone este repositório ou faça o download dos arquivos.
2. Abra o projeto no **NetBeans 8.0.1**.
3. Certifique-se de que o **GlassFish 4.1.1** está configurado e iniciado.
4. Clique com o botão direito no projeto e selecione **"Executar"**.
5. O sistema abrirá automaticamente no navegador no endereço `http://localhost:8080/CatalogoWebSimples5/`.

 📝 Observações
- O arquivo de dados `catalogo.txt` é gerado automaticamente na raiz do projeto após o primeiro cadastro.
- Este projeto foi desenvolvido com foco em boas práticas de organização de código e simplicidade de implantação.
